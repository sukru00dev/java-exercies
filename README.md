# Java Ödev Projeleri

Bu repository, Java programlama dili ile yapılmış çeşitli ödev ve alıştırma projelerini içermektedir.

## 📁 Proje Yapısı

### Ders Örnekleri
- `ders2.java` - Sayı tahmin oyunu
- `ders3.java` - Şehir sıralama programı
- `dersjava.java` - Toplama tahmin oyunu
- `javader2.java` - Dizi işlemleri örneği
- `javaders.java` - 2D dizi toplama işlemi

### Ödev 3 Serisi
- `odev_3_1.java` - Doğum günü tahmin oyunu (küme mantığı)
- `odev_3_2.java` - Çıkarma işlemi pratiği
- `odev_3_3.java` - Sayı tahmin oyunu (string manipülasyonu)
- `odev_3_4.java` - Trigonometrik fonksiyonlar
- `odev_3_5.java` - Hexadecimal karakter dönüşümü
- `odev_3_6.java` - Üçgen açı hesaplama

### Ödev 5 Serisi
- `odev_5_1.java` - RandomCharacter sınıfı testi
- `odev_5_2.java` - İki sayının maksimumunu bulma
- `odev_5_3.java` - Takvim programı
- `odev_5_4.java` - Metot parametre geçişi örneği
- `odev_5_5.java` - Hexadecimal'den decimal'e dönüşüm

### Ödev 6 Serisi
- `odev_6_1.java` - Diziyi artan sıraya göre sıralama (Bubble Sort)
- `odev_6_2.java` - Artan sıradaki dizide değer arama (Binary Search)
- `odev_6_3.java` - Sayıların ortalaması ve ortalamanın üzerindeki sayılar
- `odev_6_4.java` - 100 rastgele küçük harf ve frekans sayımı
- `odev_6_5.java` - 10 gün × 24 saatlik sıcaklık ve nem verileri

### Diğer Projeler
- `GmtTime.java` - GMT saat gösterimi
- `Main.java` - Toplama limit kontrolü programı
- `java1.java` - Asal sayı üretici
- `RandomCharacter.java` - Rastgele karakter üretici sınıfı
- `VergiHesaplayici.java` - Vergi hesaplama programı
- `SimpleBlockchain.java` - Basit blockchain örneği

## 🚀 Kullanım

Her bir Java dosyası bağımsız olarak çalıştırılabilir:

```bash
javac DosyaAdi.java
java DosyaAdi
```

## 📝 Notlar

- Tüm dosyalar Java standartlarına uygun olarak yazılmıştır
- Scanner sınıfı kullanılan dosyalarda try-with-resources kullanılmıştır
- Hata kontrolü ve kullanıcı giriş doğrulaması yapılmıştır
